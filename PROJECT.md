# Облік DEMO — GitHub Pages

## Цель и платформа

Учебное мобильное веб-приложение на React/TypeScript с Next app router и статическим экспортом для GitHub Pages. Это отдельная DEMO-пародия с вымышленными данными, без подключения к государственным системам.

## Что работает

- Главная карточка «Резерв ID» и переворот к локальному DEMO-QR.
- Оранжевый плюс открывает нижнюю панель действий.
- «Переглянути документ» открывает отдельный прокручиваемый экран с вымышленными данными, возвратом и анимированной строкой статуса.
- Вкладки «Сервіси», «Вакансії» и «Меню», локальные настройки и уведомления.
- Сохранение тестового профиля в localStorage.

## Последняя правка — 2026-09-26

Экран просмотра документа повторно откалиброван по прямому сравнению IMG_1609/IMG_1610 (оригинал) с актуальными IMG_1619/IMG_1620 (демо). Сохранена структура из пяти внешних карточек и внутренних разделителей. Исправлена типографика: вместо отсутствующего в проекте `e-Ukraine`, который на iPhone подменялся Arial, используется системная гарнитура iOS с отдельными весами подписей и значений. Панель теперь закрывается нажатием по верхней затемнённой области, по гербу, клавишей Escape и жестом вниз за верхний индикатор. Значения остаются вымышленными, DEMO-пометка сохранена.

## Как проверить

Открыть главный экран, нажать оранжевый плюс, выбрать «Переглянути документ», проверить бегущую строку и вертикальную прокрутку. Проверить закрытие жестом вниз за верхний индикатор, нажатием по верхней затемнённой области и по гербу. Нажатие по остальной карточке должно по-прежнему переворачивать её к QR.

## Ограничения и следующий шаг

В среде нет Node.js/pnpm и браузера, поэтому сборка и интерактивный рендер здесь не выполняются. Следующий шаг — заменить исходники в репозитории и проверить GitHub Actions и внешний вид на iPhone.
