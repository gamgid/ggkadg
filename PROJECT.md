# Облік DEMO — GitHub Pages

## Цель и платформа

Учебное мобильное веб-приложение на React/TypeScript с Next app router и статическим экспортом для GitHub Pages. Это отдельная DEMO-пародия с вымышленными данными, без подключения к государственным системам.

## Что работает

- Главная карточка «Резерв ID» и переворот к локальному DEMO-QR.
- Оранжевый плюс открывает нижнюю панель действий.
- «Переглянути документ» открывает отдельный прокручиваемый экран с вымышленными данными, возвратом и анимированной строкой статуса.
- Вкладки «Сервіси», «Вакансії» и «Меню», локальные настройки и уведомления.
- Сохранение тестового профиля в localStorage.

## Последняя правка — 2026-09-26

Экран просмотра документа повторно откалиброван по прямому сравнению IMG_1609/IMG_1610 (оригинал) с актуальными IMG_1619/IMG_1620 (демо). Сохранена структура из пяти внешних карточек и внутренних разделителей. Для этого экрана подключена оригинальная гарнитура `e-Ukraine` в начертаниях Light, Regular и Medium; файлы берутся из публичного зеркала фиксированной ревизии, источник и лицензия указаны в `FONT-ATTRIBUTION.md`. Жест закрытия переделан: панель следует за пальцем, учитывает дистанцию и скорость, плавно возвращается при отмене и срабатывает только с верхней зоны, когда прокрутка находится в начале. Нажатие по затемнённой области, гербу и Escape также закрывает экран. Значения остаются вымышленными, DEMO-пометка сохранена.

## Как проверить

Открыть главный экран, нажать оранжевый плюс, выбрать «Переглянути документ», проверить гарнитуру, бегущую строку и вертикальную прокрутку. Потянуть вниз за индикатор или заголовок: экран должен двигаться за пальцем; короткий медленный жест должен вернуть его на место, а достаточно длинный или быстрый — закрыть. При прокрученном документе жест закрытия не должен перехватывать прокрутку. Также проверить закрытие нажатием по верхней затемнённой области и по гербу. Нажатие по остальной карточке должно по-прежнему переворачивать её к QR.

## Ограничения и следующий шаг

В среде нет Node.js/pnpm и браузера, поэтому сборка и интерактивный рендер здесь не выполняются. Для первой загрузки файлов шрифта требуется интернет. Следующий шаг — заменить исходники в репозитории и проверить GitHub Actions, жест и внешний вид на iPhone.
